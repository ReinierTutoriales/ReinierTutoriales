## Focus

**OpenCore · macOS · Hackintosh · EFI · Wi-Fi / Bluetooth · Hardware compatibility**

Trabajo principalmente con configuraciones Intel y AMD, documentación de EFI, compatibilidad de hardware y resolución de problemas relacionados con macOS en equipos no soportados.

La prioridad es mantener configuraciones **claras, reproducibles y verificables**, evitando modificaciones innecesarias.

---

## Selected work

### OpenCore & macOS

**[OpenCore Legacy Patcher](https://github.com/ReinierTutoriales/OpenCore-Legacy-Patcher)**
Fork orientado a pruebas, compilación y adaptación de OpenCore Legacy Patcher.

**[itlwm · AirportItlwm · LQM](https://github.com/ReinierTutoriales/itlwm-AirportItlwm-LQM)**
Trabajo sobre Intel Wi-Fi, AirportItlwm y la implementación LQM para macOS.

**[Intel AX210 · macOS](https://github.com/ReinierTutoriales/Intel-AX210-macOS-Sonoma-Sequoia-Tahoe)**
Configuración y documentación de Intel AX210 para Sonoma, Sequoia y Tahoe.

**[Broadcom Wi-Fi / Bluetooth](https://github.com/ReinierTutoriales/Broadcom-WiFi-Bluetooth-macOS-Sequoia)**
Documentación de compatibilidad Broadcom, Wi-Fi, Bluetooth y configuración en Sequoia.

**[Ryzentosh · Ryzen 7 5800U](https://github.com/ReinierTutoriales/Ryzentosh-GenMachine-Rem5000-Ryzen-7-5800U)**
Configuración específica de macOS sobre AMD Ryzen 7 5800U.
